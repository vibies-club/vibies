# Landing page brief

[Documentation home](../README.md) · [Product](PRODUCT.md) ·
[Issue #51](https://github.com/vibies-club/vibies/issues/51)

The public home page at `/` introduces Vibies to beginners in the class. Keep
the copy short. Every line below is the exact page copy.

## Hero

**Headline:** Build real projects together.

**Supporting sentence:** A private, instructor-led community for beginners.

**Main action:** A "See what's coming" button scrolls to the Coming soon
section. It is the only button on the page.

**Show a real project:** Vibies itself, built by the class, with the real
Vibies logo. Six small cells around the bee mascot show:

- Vibies: Our class project
- GitHub sign-in: Done
- Project sharing: Done
- Open source: On GitHub
- Feedback: Planned
- Built by the class

**Caption:** Real project · Vibies, built by our class

**Project window title:** github.com/vibies-club/vibies

## Problem

**Headline:** Progress is hard alone.

**Body:** Vibies gives beginners a private place to share work as it grows.

## How it works

1. **Get access:** Sign in with GitHub. Your instructor approves you.
2. **Share a project:** Connect a repository and describe it in your words.
3. **Build together:** Show progress and give useful feedback.

## The Vibies project card

**Title:** Vibies

**Owner line:** Built by our class

**Summary:** The private home for our class projects. We build it in the open,
one pull request at a time.

**Link:** See the code on GitHub, to `github.com/vibies-club/vibies`.

**Roadmap:** GitHub sign-in (Done), Project sharing (Done), Feedback (Planned).
Update these states when the [roadmap](ROADMAP.md) changes.

## Benefits

**Headline:** A place for the work as it grows.

- **Visible progress:** Share a project and its next step.
- **Learn by making:** See what others build and talk about it.
- **Private by design:** Instructor approval. Nicknames only.

## Coming soon

**Headline:** Coming soon.

**Body:** Ask your instructor for an invitation.

## Footer

The Vibies logo and name, and a link to the community rules. No other button.

## Limits

The page uses no reviews, user numbers, statistics, or Member projects. Showing
a Member's project needs that Member's separate consent for marketing use.
